# marching-cubes-rs

Rust implementation of the marching cubes algorithm, with the use of lookup tables.
Currently it is only a learning project, meant to be used in another learning project, no changes to that state in sight.

## Features
Currently:
- Simple implementation, simple use, dependency free

Planned:
- Input validation and proper error types
- Test suite
- Performance work, including optional parallel extraction with rayon
